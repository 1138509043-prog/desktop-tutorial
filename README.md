4. 困ったこと・課題
 
ゲームモデリング生成では、モデルと当たり判定の位置がずれる問題や、迷路の通路が正しくつながっているかの確認、ギミックの配置確認に苦労している。また、時間を戻す機能とギミックの作動状態やプレイヤーの位置を正しく保存・復元する点も難しい。
 
スキル設定の妥当性も課題である。戻れる秒数、クールダウン、使用回数などの設定が適切でないと、スキルが強すぎてパズル性が低くなったり、弱すぎて失敗が多くなったりする。そのため、ギミック配置とスキル性能を何度も調整しながら、ゲームバランスを確認する必要がある。
 
さらに、メンバーが別々に制作した部分をどのように統合するかも考える必要がある。まずは基本的な移動と迷路、時間を戻す処理の調整を完成させたい。
