1. ゲーム概要
 
本作「時間を戻す迷路」は、プレイヤーが迷路を探索しながら、ボタン一つで数秒前の位置まで戻ることができるゲームである。単純にゴールを目指すだけではなく、時間を戻す能力を解謎要素として使う点が特徴である。
 
特に、一部のギミックは先に作動させ、その後に時間を戻ることで初めて先へ進める仕組みになっている。つまり、プレイヤーは「現在の行動」と「過去に戻った後の状態」の両方を考える必要がある。
 
2. 開発進捗
 
現在、ゲームの基本フレームワークは完成している。具体的には、プレイヤーの移動、迷路マップの生成、ギミックの起動、時間を戻すスキル、初期位置へのリセットなど、基本的な機能を実装した。
 
現在は、実装した内容のデバッグを行いながら、ギミックと時間逆行の同期確認、UIや演出の調整、難易度バランスの確認、ゲームプレイの最適化を進めている。進捗としては、基本部分は完了しており、内容の調整と遊びの最適化の段階である。

3. 開発中に遭遇した困難
 
3.1 ゲームモデリング生成の困難
 
迷路やギミックのモデリング生成では、見た目のモデルと当たり判定の位置がずれる問題が発生した。また、迷路を生成した後に、通路が正しくつながっているか、ギミックが正しい位置に配置されているかを確認する必要があった。
 
さらに、時間を戻す機能とモデルの状態を同期させる必要があり、ギミックの作動状態やプレイヤーの位置を正しく保存・復元する点に苦労した。モデル生成の段階で問題があると、後のデバッグが非常に難しくなるため、小さな範囲でテストを繰り返しながら調整した。
 
3.2 スキル設定の妥当性の困難
 
時間を戻すスキルの設定も難しい問題であった。戻れる秒数、クールダウン時間、使用回数などのパラメータが適切でないと、ゲームバランスが大きく崩れる。
 
例えば、時間を戻す能力が強すぎると、ギミックを先に作動させる意味が薄れ、パズル性が低くなる。逆に弱すぎると、プレイヤーが何度も失敗し、ゲームとしての楽しさが損なわれる。そのため、ギミックの配置とスキルの性能を何度も調整し、試遊しながらバランスを確認した。
 
4. 解決方法と工夫
 
モデリング生成については、迷路やギミックを小さな単位で作り、モデルと当たり判定を分けて確認するようにした。また、生成後に通路やギミックの位置をチェックし、問題がある場合はすぐに修正できるようにした。
 
スキル設定については、戻れる時間やクールダウンなどをパラメータとして管理し、試遊を繰り返しながら調整した。特に、ギミックを先に起動してから時間を戻るという流れが自然に理解できるように、配置やヒントの出し方を工夫した。
