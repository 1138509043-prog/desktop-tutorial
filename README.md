## 4. 困ったこと・課題
 
ゲームモデリング生成では、見た目のモデルと当たり判定の位置がずれる問題があり、迷路の通路が正しくつながっているか、ギミックが適切な位置に配置されているかを確認するのに時間がかかっている。また、時間を戻す処理で、ギミックの状態やプレイヤーの位置を正しく保存・復元する点も難しい。
 
スキル設定の妥当性も課題である。時間を戻す能力が強すぎると、ギミックを先に作動させる意味が薄れてパズル性が下がる。逆に弱すぎると、失敗が多くなりゲームとしての楽しさが損なわれる。そのため、戻れる秒数やクールダウンを試しながら、ギミック配置とのバランスを調整する必要がある。
